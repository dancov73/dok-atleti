# Tekna Dok, la web app degli atleti

Pagine statiche, senza librerie. I sorgenti stanno nel repository di Tekna Dok, cartella `web/`: questo repository serve solo a pubblicarle.
I dati non stanno qui: arrivano dal cloud di Dok, dopo l'accesso, e le regole del database mostrano a ogni atleta solo ciò che è suo.
L'indirizzo del progetto e la chiave pubblicabile sono pubblici per costruzione.
